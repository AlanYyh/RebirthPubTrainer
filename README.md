# Rebirth Pub Trainer

《Rebirth Pub》单机游戏的修改工具，免费、开源。

## 功能

- 货币 / 资源：金币、魂石、行动点、体力、技能点
- 角色好感度：3 位女主角 + 13 位 NPC
- 道具数量：全部道具
- 技能等级：全部探索技能
- 图鉴 / 收集：一键解锁图鉴、服装、遗物

界面基于 WebView2 渲染，左侧分类、右侧列表、点击即可修改，底部有状态提示。

## 使用

1. 把 `RebirthPubTrainer.exe` 放到游戏根目录（与 `Rebirth Pub.exe` 同一目录）。
2. 首次启动修改器会自动安装注入组件（BepInEx 与 WebView2 运行文件）。
3. 启动游戏并载入存档。
4. 在修改器左侧选择分类，点击列表项输入新值，修改即时生效。

需要系统已安装 Microsoft Edge WebView2 运行时（Windows 10/11 一般自带）。

## 版本

- 修改器版本：1.0
- 对应游戏版本：0.65

## 工作原理

修改器通过本机回环地址（127.0.0.1）与游戏内加载的插件通信，实时读写游戏数据。
全程只在本地运行，不联网、不采集任何信息。

## 安全说明

本项目完全开源，源码可自行审查。修改器仅在本机运行：

- 不包含任何网络上传、下载或数据采集逻辑
- 不修改游戏文件
- 注入组件为标准 BepInEx 框架，卸载时删除对应文件即可

## 构建

需要：

- Windows 与 .NET Framework 4.x（系统自带）
- 游戏本体（编译插件时需要引用游戏的 Managed 程序集）
- BepInEx 5.x
- WebView2 SDK（NuGet 包 `Microsoft.Web.WebView2`，解压后填到脚本里的 `$webView2Dir`）

编译脚本见 `build/` 目录，使用前请把脚本中的路径改成你的实际路径。
